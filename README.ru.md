## GitHub vs Quartz

Markdown на GitHub не поддерживает большинство удобных функций маркдауна Obsidian. Этот шаблон корректно рендерит на сайте:
- **Вики-ссылки:** `[[Имя заметки]]` и `[[Имя заметки|Кастомный текст]]` с авто-поиском путей.
- **Коллауты:** теперь доступны `> [!quote]`, `> [!success]`, `> [!bug]` и другие. Поддерживается сворачивание и кастомные заголовки (`> [!note]- Уточнение`, `> [!important]+ Важно!`).
- Поддерживаются файлы Obsidian Bases (`.base`) и Canvas (`.canvas`), а также многое другое.

## Быстрый старт: как создать свой сайт за 1 минуту

1. Нажмите зелёную кнопку **Use this template** вверху страницы и выберите **Create a new repository**
2. В новом репозитории откройте **Settings** > **Pages** и выберите **GitHub Actions** как источник публикации
3. Склонируйте репозиторий на своё устройство
4. Отредактируйте `content/index.md` или добавьте заметки, затем создайте коммит и отправьте изменения в `main`. Каждый следующий push в `main` будет запускать публикацию автоматически
5. Адрес сайта указан в **Settings** > **Pages**. Обычно сайт проекта доступен по адресу `https://{user}.github.io/{repo}`

Инструкция по настройке собственного домена есть в заметке [Быстрый старт](content/docs/ru/quick-start.md).

>[!important]
>Важно, чтобы в папке `content/` всегда была заметка `index.md`. Именно она открывается при переходе на сайт `https://{user}.github.io/{repo}`. Без неё публикация не получится

>[!note]
>При нажатии на папку на сайте открывается `index.md`, а если его нет, то простой список всех файлов в папке

>[!tip]
>Чтобы в левом верхнем углу установить вашу надпись вместо `Quartz 5`, просто перейдите в `quartz.config.yaml` и введите вашу строку в этом блоке вместо `Quartz 5`:
> ```yaml
> configuration:
>   pageTitle: Quartz 5
> ```
>
### Удобное пользование

>[!important]
>Для удобства работы с заметками рекомендуется открывать не сам репозиторий как Vault, а именно папку `content/`. Название может оказаться неудобным, если у вас несколько Vault. Для изменения названия папки заметок:
>1.  Переименуйте папку `content/` так, как вам удобно. Например, в название вашего репозитория
>2. Перейдите в файл `.github/workflows/deploy.yml` и сделайте следующее изменение:
> ```yml
> # Было:
>       - name: Build Quartz
>         run: npx quartz build
>
> # Стало (например, если папка называется notes):
>       - name: Build Quartz
>         run: npx quartz build -d notes
> ```
>Теперь после каждого `push` сайт будет собираться из указанной вами папки с заметками.

>[!tip]
>Все заметки вы можете называть на русском, однако при копировании ссылки сайта зачастую она превращается в это: `https://{user}.github.io/{repo}/path/to/note/#%D0%B4%D0%BE%D0%B1%D1%80%D0%BE-%D0%BF...`.
>
>Чтобы этого избежать, рекомендуется давать заметкам английские названия без пробелов, а отображаемые названия указывать в свойстве `title`. Quartz автоматически извлекает его из заметки. Пример такого подхода можно увидеть в уже созданном файле `content/index.md`.

>[!note]
>Если вы хотите изменить язык интерфейса на русский, откройте `quartz.config.yaml` в корне репозитория и замените `locale: en-US` на `locale: ru-RU`. Сам я предпочитаю этого не делать: шрифт сайта не рассчитан на русский, поэтому текст может выглядеть мельче.

## Локальный запуск и тестирование

Для предварительного просмотра сайта на локальной машине необходим установленный [Node.js](https://nodejs.org/) (версии 22 или новее). Перейдите в корень склонированного репозитория и выполните:

```bash
# 1. Установка зависимостей
npm ci

# 2. Установка плагинов Quartz
npx quartz plugin install --from-config

# 3. Запуск локального сервера (если папка стандартная 'content')
npx quartz build --serve

# Если вы переименовали папку (например, в notes):
npx quartz build --serve -d notes
```

После выполнения команд терминал покажет адрес сайта. Обычно это [http://localhost:8080](http://localhost:8080). Изменения файлов в папке `content/` автоматически обновляют страницу.

### Служебные файлы и Git
В процессе установки зависимостей и сборки локально создаются следующие директории:
- `node_modules/` — библиотеки и зависимости проекта;
- `public/` — скомпилированный статический сайт (HTML, JS, CSS, сгенерированные графы);
- `.quartz-cache/` — кэш парсера Markdown для ускорения повторных сборок.

Все эти папки уже прописаны в `.gitignore`, поэтому они не попадут в ваш GitHub-репозиторий.
