# Как внести вклад

Спасибо, что хотите помочь проекту! Мы приветствуем любые улучшения — от исправления опечаток до добавления новых функций в шаблоны или скрипты.

## 🚧 Быстрый старт

1. Сделайте **Fork** репозитория.
2. Склонируйте его и внесите правки в Markdown-заметки или код.
3. Перед созданием PR рекомендуется проверить заметки скриптом нормализации:
   ```bash
   python scripts/main.py --check
   ```
4. Если скрипт нашел ошибки, исправьте их автоматически:
   ```bash
   python scripts/main.py
   ```
5. Создайте **Pull Request** в ветку `main`.

## Оформление заметок

Мы стараемся придерживаться чистого и понятного синтаксиса. Подробности можно найти в разделе [Features](docs/ru/features) и [Markdown Normalization](docs/ru/normalization). Не переживайте, если что-то оформите не так — наши скрипты и CI помогут привести всё к каноничному виду.

## Локальный запуск

Если вы хотите посмотреть, как ваши изменения выглядят на сайте:

```bash
npm ci
npx quartz plugin install --from-config
npx quartz build --serve
```

Сайт будет доступен по адресу [http://localhost:8080](http://localhost:8080).

## 🔧 Скрипты и тесты

Если вы меняете логику в папке `scripts/`, обязательно запустите тесты:
```bash
python -m unittest discover -s scripts/tests -t .
```
