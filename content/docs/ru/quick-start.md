### 🚧 Быстрый старт: публикация сайта

1. Перейдите в [репозиторий шаблона](https://github.com/sergeypugin/quartz-ready-template), нажмите зелёную кнопку **Use this template** и выберите **Create a new repository**.
2. В новом репозитории откройте **Settings** > **Pages** и выберите **GitHub Actions** как источник публикации.
3. Чтобы запустить первую публикацию, откройте **Actions**, выберите **Deploy Quartz site to GitHub Pages**, нажмите **Run workflow** и выберите ветку `main`.
4. Отредактируйте `[[index|content/index.md]]` или добавьте Markdown-заметки, затем создайте коммит и отправьте изменения в `main`. В дальнейшем каждый push в `main` будет запускать публикацию автоматически.
5. Адрес сайта будет указан в **Settings** > **Pages**; проектные сайты обычно доступны по адресу `https://{user}.github.io/{repo}`.

> [!note] Организация файлов
> - Главная страница сайта находится в файле `content/index.md`.
> - Quartz собирает сайт из файлов в папке `content/`; Obsidian не требуется. Если вы редактируете заметки в Obsidian, эту папку можно открыть как Vault.
> - При открытии папки на сайте Quartz показывает её файл `index.md`, если он есть; иначе показывает список файлов в папке.

### Работа с заметками

> [!tip] Настройка и именование
> - Чтобы изменить язык интерфейса Quartz, укажите значение `locale` в `quartz.config.yaml` (например, `locale: ru-RU`).
> - Заметки можно называть на любом языке. Чтобы адреса были проще, используйте английские имена файлов без пробелов, а отображаемое название задавайте свойством `title` в frontmatter.
